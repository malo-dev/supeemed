#tantoforma

Bienvenue sur le projet **TANTOFORMA** ! Il s'agit d'une application web inspirée de [LegalStart.fr](https://www.legalstart.fr/), qui permet aux utilisateurs de créer facilement leur propre entreprise en ligne, y compris des entreprises SaaS, en suivant des processus simplifiés.

---

## **Fonctionnalités principales**

### 1. **Gestion de la création d'entreprise**

- Processus guidé pour créer une entreprise (Société à Responsabilité Limitée, SAS, SASU, etc.).
- Génération automatique des documents juridiques (statuts, PV, déclaration de bénéfices, etc.).
- Intégration avec les services administratifs pour simplifier les démarches.

### 2. **Espace utilisateur personnalisé**

- Tableau de bord personnel pour suivre l'état des démarches.
- Historique des actions effectuées.
- Notifications en temps réel pour les étapes importantes.

### 3. **Gestion des documents**

- Système de téléversement des documents nécessaires (pièces d'identité, justificatifs de domicile, etc.).
- Organisation et stockage sécurisé des documents sur le cloud.

### 4. **Paiement en ligne**

- Options de paiement sécurisé (Stripe, PayPal).
- Gestion des factures pour les services réalisés.

### 5. **Support client**

- Chat en direct avec des conseillers.
- Base de connaissances enrichie.
- Système de tickets pour les demandes spécifiques.

---

## **Technologies utilisées**

### **Front-end**

- **React.js** avec **Redux Toolkit** pour la gestion de l'état.
- **Tailwind CSS** pour un design moderne et réactif.
- **TypeScript** pour une meilleure robustesse et maintenabilité.

### **Back-end**

- **Express.js** écrit en TypeScript.
- **JWT** (JSON Web Token) pour l'authentification.
- **Mongoose** pour la gestion de la base de données MongoDB.
- Intégration de services tiers (Stripe, PayPal).

### **Outils de gestion de projet**

- **GitHub** pour la gestion du code source et le suivi des issues.
- **Trello** pour organiser les tâches et suivre l'avancement du projet.

### **Hébergement**

- Front-end et back-end déployés sur **Hostinger**.

---

## **Structure du projet**

### Dossiers principaux

- `apps/client` : Contient le code front-end (React).
- `apps/server` : Contient le code back-end (Express).

### Scripts pour lancer le projet

- **Front-end** :
  ```bash
  npm run apps/client
  ```
- **Back-end** :
  ```bash
  npm run apps/server
  ```
